# Ruolo di questo template

**Applicazione realistica** — integrazione HomeAssistant di base: sensori, binary_sensor,
attributi, luci/switch e input_number in scrittura, tag derivati, allarmi, su 3 pagine
(Panoramica, Controllo, Storico).

## Il metro con cui giudicarlo

Deve somigliare a un impianto vero collegato ad HomeAssistant, con la profondità che serve a
capire l'integrazione (lettura, scrittura, derivati, allarmi) senza pretendere di coprire ogni
capacità possibile — quello è il ruolo di `homeassistant-pro`, il gemello "completo".

Non giudicarlo con il metro dell'inventario (non deve coprire ogni tipo di oggetto) né con
quello di un banco di prova di protocollo (qui il protocollo — l'integrazione HA via
WebSocket — è già dato per assodato altrove; il punto è come si compone un impianto sopra).
